# Exoplanets — Data Analysis

Exploratory data analysis of an exoplanets dataset: cleaning, visualising,
and drawing insights from the data, followed by a short presentation of the
findings.

## Context
Completed as a **timed, one-hour exam** — closed-book, with no internet,
documentation, or external help — then presented live. The goal was to go
from raw dataset to clear findings quickly and independently.

## Files
- `Data_analysis_report.ipynb` — the full analysis.
- `Exoplanets Dataset Analysis Report.pdf` — written report.
